# Homeworks logo (2026-09-23)

The owner supplied a reference image of the Homeworks logo. Recreate its large HOME (off-white) / WORKS (deep red) wordmark, thin rules, and the exact two supporting lines. The full composition is in `public/brand/logo.svg` on the near-black background, with a transparent `lockup.svg` for the footer.

`npm run logo` outlines the lettering in standalone SVGs. `public/brand/logo.png` is a 2× raster export for sharing. The header uses a compact light-background wordmark; the footer uses the full lockup. The favicon uses a W derived from the wordmark.
